## 2. 往届主板现有功能

现有主板以插接 MCU 核心板的方式工作。以下为结合原理图和往届固件静态核对得到的基线：

- **视觉**：MT9V03x 摄像头经 AL422B FIFO 输出 8 位数据；图像分辨率为 188×120。旧固件有摄像头采集和循迹处理代码。
- **驱动与运动**：双路 DRV8701 栅极驱动器配外置 MOSFET 桥，连接左右两路有刷电机；两路编码器、舵机接口均已布出。
- **姿态**：原理图标注 BMI270；旧固件所用 IMU 驱动库名称为 IMU660RA，需查实装器件和初始化配置是否一致。
- **扩展**：SPI 屏幕、Wi-Fi 排针、激光/ULN2003、测距传感器接口、按键与蜂鸣器。
- **电源**：电池输入经过保护和降压，板上有 5 V、3.3 V、摄像头电源等不同网络。核心板接入时需核对每个电源网的方向、实测电压和允许电流。

旧主板目前没有从原理图确认出专用的电磁门接收前端。测距传感器接口的两条信号是 I²C 网名；只有在新核心板将其映射为所需 ADC/UART 功能、且确认电平和上拉适配后，才可考虑改作接收板接口。

## 3. 固件静态核对结果

三个旧固件压缩包中的主流程与设备驱动可作为理解旧板的参考，但不能直接当作本届已适配固件：

- 主循环以 5 ms 周期处理陀螺仪、编码器、按键和运动控制，并读取摄像头图像。
- 视觉包含循迹、环岛、半圆、斑马线等旧赛道逻辑；发布源码中的十字路口处理调用处处于注释状态。
- 旧源码没有本届电磁门进入/离开判定、门后任务状态切换和两圈流程逻辑。
- 测距、Wi-Fi、部分 ADC 功能在旧固件中未启用或没有接入当前主流程。
- 三个版本有少量参数与图像处理差异，需以目标版本逐项移植，不要混合宏定义和设备驱动。

## 4. AURIX 核心板方向

第一版核心板候选为 **SAK-TC264D-40F200W BC**（LQFP-144）。选择它的原因是可通过多个插接排针匹配旧主板，并提供摄像头 FIFO 并口采样、定时器 PWM、编码器计数、SPI 和 UART 等资源。候选引脚分配已经按原理图端口做过初步核查，但尚未冻结。

设计冻结前至少完成：

1. 对照主板和核心板 PCB 实物确认五组插座的间距、方向、针序、板间高度和固定方式。
2. 按 TC264D 原厂数据手册核对封装脚号、电源域、I/O 电压、复用功能和启动/调试脚。
3. 测量旧主板电源输出与核心板输入；特别检查原理图反馈电阻标注与网名不一致处。
4. 确认摄像头 FIFO 的写入控制、读时钟和帧同步时序可由新 MCU 实现。
5. 做限流上电和分模块验证，再接驱动、电机和舵机。

参考：[Infineon TC264D 产品页](https://www.infineon.com/part/SAK-TC264D-40F200W-BC)、[TC26x BC-Step 数据手册](https://www.infineon.com/assets/row/public/documents/10/49/infineon-tc26xbc-datasheet-en.pdf)。

## 5. 当前判断

旧主板可作为**学习、移植和原型联调底板**，但不等于已经能完整应对本届比赛。硬件上需要增加电磁接收能力；固件要新增电磁门状态机、赛道任务转换和启停流程；正式参赛前还需复核板卡制作及模块使用规则，并完成实车验证。
