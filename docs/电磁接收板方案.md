# 电磁接收板方案

更新：2026-11-20  
状态：架构建议，尚未完成原理图和实测

## 决策

电磁接收部分采用**独立、可插拔的车载接收板**，先不并入往届主板。旧主板和 AURIX 核心板继续负责车辆控制；接收板靠近车头线圈安装，通过短线将供电、地和信号送到 AURIX 核心板。

拆板的主要好处是线圈和微弱模拟信号可以远离电机桥、开关电源等噪声源；接收电路可以单独测量、调试和更换；同时保留旧主板，不影响已有底板的功能。往届开源设计中也有将电感安装板与主控板分开的做法，可参考其结构和接口思路，但不能直接照搬为本届已验证方案：[开源硬件参考](https://oshwhub.com/z.y.b1/project_kqpyqauo)。

## 建议的信号链

```
正交接收线圈
    ↓
输入保护与模拟调理
    ↓
两路接收信号
    ↓
AURIX ADC 采样与方向/强度计算
    ↓
本届电磁门状态机与车辆控制
```

第一版建议让接收板包含线圈接口、输入保护、模拟调理、必要的滤波/增益设置、去耦和板间连接器；把方向计算和比赛逻辑放在 AURIX 固件中。这样可以直接观察两路波形与幅值，也避免在接收板上额外放一颗 MCU。额外 MCU 是否允许应以本届正式规则为准。

## 接口规划原则

接口针数和电路尚未冻结，初步按以下信号规划：

| 信号 | 用途 |
|---|---|
| 电源 | 给接收前端供电；电压与噪声要求待器件选型后确定 |
| GND | 模拟/数字回流参考，布局需避免电机大电流回路经过线圈区域 |
| CH1 | 第一路线圈的调理输出，优先送 AURIX ADC |
| CH2 | 第二路正交线圈的调理输出，优先送 AURIX ADC |
| 预留 | 可留同步/状态或备用模拟输入；具体取舍待测量后定 |

旧主板的 DISTANCE_SENSORS 接口带 +5 V、GND 和两条标成 SCL/SDA 的信号。它们只有在新核心板上选择合适的 ADC 引脚、移除原测距模块并核实电平/上拉后，才可能用于临时接入。也可以由新核心板专门引出接收板接口，避免复用约束。当前不能把它当作已经确认的接收板接口。

## 频率与检测方式

第 22 届电磁门公开资料给出的发射器推荐工作频率示例为 150 kHz，并说明比赛使用组委会提供的门体和比赛控制系统；这属于**发射端参考信息**，不代表接收端的官方信号接口或频率容差已经完全确定。应在正式参数和实测波形确认后，才定接收前端带宽、增益、采样率和滤波参数。

接收板必须保留足够信息来判定方向。不能只凭“两个线圈有信号”就确定方向算法，也不要在尚未验证时把信号整流成只剩幅值。先在门前、门中心、门后以及不同偏角处记录两路原始波形/包络，确认相位、极性、幅值与方向的关系，再决定模拟解调方式。

## 快速原型

可先用第 21 届电磁门穿越的正交线圈定向模块做对照。公开资料描述该模块通过 UART 输出解算角度与两路信号强度；第 22 届发射器规格验证也沿用了该定向模块。这有助于验证线圈安装位置和控制方向，但 115200 UART 等信息是往届模块接口，不能直接认作本届比赛的官方协议：[往届定向模块介绍](https://www.eet-china.com/mp/a509847.html)、[本届发射器说明](https://www.eet-china.com/mp/a540577.html)。

## 开板前需要补齐

- 两路线圈的尺寸、轴向、固定位置和接线极性。
- 实际接收波形、最小/最大信号幅度和门体频率范围。
- 放大器输入范围、噪声、增益、带宽和输出范围。
- AURIX ADC 采样脚、采样率和输入电压范围。
- 接收板供电来源、模拟回流、连接器方向和线缆长度。
- 赛事对接收板、外购模块和额外处理器的限制。
- 旧主板核心板排针及空闲信号的实物映射。

选型与原理图阶段以模拟前端器件及 AURIX 的原厂数据手册为依据；开源板和往届模块作为实现参考与对照测试。
