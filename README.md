# OIL-BUG｜铁人智能车

第 22 届全国大学生智能汽车竞赛「走街串巷」项目资料与硬件迭代记录。

## 项目方向

- 四轮车模，比赛指定使用 Infineon AURIX MCU。
- 以往届主板作为学习和联调底板，计划设计可插接的 AURIX 核心板。
- 保留摄像头视觉循迹、电机与舵机控制等现有功能；按本届任务补充电磁门接收与赛事状态处理。
- 资料优先以原厂数据手册、公开规则和实际原理图为依据。
